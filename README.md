# nist-csf-cis-control-mapping
# NIST CSF 2.0 to CIS Controls v8.1 Mapping

## Project Overview

This project explores the relationship between the NIST Cybersecurity Framework (CSF) 2.0 and CIS Critical Security Controls v8.1 from a Governance, Risk and Compliance (GRC) perspective.
It demonstrates how practical cybersecurity safeguards can support strategic cybersecurity outcomes, helping organizations translate framework requirements and objectives into actionable security measures.

## Objectives

- Understand the relationship between cybersecurity frameworks.
- Map selected NIST CSF 2.0 subcategories to CIS Controls v8.1 safeguards.
- Evaluate the degree of alignment between cybersecurity outcomes and safeguards.
- Identify potential coverage limitations.
- Provide practical implementation examples and potential audit evidence.

## Frameworks

### NIST Cybersecurity Framework 2.0

NIST CSF 2.0 provides a structured approach to understanding, managing and reducing cybersecurity risk through six core functions:
- Govern 
- Identify 
- Protect
- Detect
- Respond
- Recover

### CIS Controls v8.1

The CIS Controls provide a prioritised set of actionable cybersecurity safeguards designed to help organisations protect their systems, networks and information assets.

## Project Scope

The project examines 12 selected NIST CSF 2.0 subcategories across all six core functions and maps them to relevant CIS Controls v8.1 safeguards.
The assessment focuses on conceptual alignment rather than organizational compliance or implementation maturity.

## Methodology

Each mapping is evaluated using three alignment levels:

| Alignment | Description |
|---|---|
| Strong | The safeguard directly and substantially supports the NIST outcome. |
| Partial | The safeguard supports part of the outcome but additional measures may be necessary. |
| No direct alignment | No directly relevant safeguard was identified within the reviewed scope. |

Each mapping includes a rationale, an implementation example, potential audit evidence and coverage limitations.

## Limitations

This project is an educational portfolio exercise. It does not represent an official framework crosswalk, a formal compliance assessment or a security audit.
The alignment classifications are project-specific analytical judgments and do not establish framework equivalence or organizational compliance.
